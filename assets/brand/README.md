# Dougong 标志使用规范

> 一页纸。够用即止——这份文档的读者是要把 logo 用起来的人，不是设计师。

## 一、标志构成

**阶梯环**：两条折线各自走台阶，在中间交叠，形成一个循环结构。

```
56 184 ─┐          ┌─ 184 56
        │          │
   128 ─┘      ┌───┘ 112
        ┌──────┘
    88 ─┘          └─ 152
        │          │
    48 ─┘          └─ 192
```

它不是任何具象物的描绘。两条线互相承接、交替上升——这是"层层承托"的抽象表达，也是 Dougong 作为 harness 的定位：**承托而不替代**。

## 二、颜色

```
玄黑  #0E0E11     底板
米白  #F5F1E8     线条
```

**只有两个颜色。** 不使用第二彩色、不使用渐变、不使用阴影。

> **早期方案曾用琥珀 `#E8A317` 点缀中心**，后因"太突兀、与线构抢注意力"而移除。
> 纯线构本身已有足够识别度。

## 三、五个变体与使用场景

| 文件 | 场景 |
|---|---|
| `icon-primary.svg` | **主用**。深色背景、应用图标、GitHub 头像 |
| `icon-inverse.svg` | 与 primary 相同，但无圆角底板时使用 |
| `icon-flat.svg` | 白底文档、印刷品、PPT |
| `icon-mono-white.svg` | 深色底上的纯白线（不放底板） |
| `icon-small.svg` | **16–48px 专用**。台阶减到 2 级、线宽加大 |

### 为什么要有小尺寸专用版

四级台阶在 16px 下会糊成一个点——这是几何上的固有限制，不是缺陷。
`icon-small.svg` 把台阶减到两级、线宽从 24 加到 34，16px 下仍能辨认。

**尺寸对应关系（已实测）**：

```
1024 512 256 128 64  →  icon-primary.svg
48 32 16             →  icon-small.svg
```

## 四、最小尺寸

| 场景 | 最小尺寸 |
|---|---|
| 屏幕 | 16px |
| 印刷 | 8mm |

**低于 16px 不要使用**，结构会消失。

## 五、安全区

标志四周留白至少等于**一个台阶的高度**（约标志边长的 1/8）。

```
┌─────────────────────┐
│   ┌───────────┐     │
│   │           │     │  ← 留白 ≥ 1/8 边长
│   │   标志     │     │
│   └───────────┘     │
└─────────────────────┘
```

## 六、禁止的用法

| 禁止 | 原因 |
|---|---|
| 旋转（除 90° 的整数倍） | 阶梯的"上升"方向有意义，转了就反了 |
| 拉伸变形 | 台阶必须是正方形 |
| 改变线宽与台阶的比例 | 比例是这个标志的全部 |
| 加投影、发光、描边 | 会破坏纯线构 |
| 用其他颜色 | 见 §二 |
| 放在花哨背景上 | 细线在复杂背景上消失 |
| 缩小到 16px 以下 | 见 §四 |

## 七、与文字的组合（排版规范）

**不提供 SVG 字标路径。** 原因：`<text>` 元素依赖机器字体，转成路径需要字体解析工具（本机没有），而给出会变的文件比不提供更糟。

**组合时用 CSS / 应用排版**：

```css
.brand-wordmark {
  font-family: -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
  font-weight: 600;
  letter-spacing: -0.02em;
  font-size: 1em;           /* 相对图标高度的 0.45 倍 */
  text-transform: lowercase; /* 一律小写 */
}
```

**已实测的最佳组合**：

```
图标 128px  +  dougong  semibold 62px  -0.02em  lowercase
间距        图标右边到文字左边 = 36px（图标宽度的 28%）
垂直对齐    文字的 x-height 中心 对齐 图标中心
```

试过的其他组合及结果：

| 组合 | 结果 |
|---|---|
| **Semibold, -0.02em, 小写** | **最佳**。字重的圆润与图形的圆角呼应 |
| Bold, -0.03em | 偏重，压过图标 |
| Medium, 0 | 偏轻，像系统文字而非品牌 |
| CAPS, +0.08em | 太硬，与圆角图形冲突 |

**为什么一律小写**：小写的 `dougong` 有多个圆形字腔（o、g），与标志的圆角构成呼应；全大写会丢掉这个关系。

## 九、什么没做

| 项 | 状态 |
|---|---|
| SVG 字标路径 | **不提供**。需要字体解析工具；`<text>` 版本的审计判定为 FAIL（73/100） |
| 商标检索 | **未做**。正式启用前应做反向图片搜索与商标库检索 |
| 图形 icon 之外的应用图标变体（如 macOS 圆角规格、Android adaptive icon） | 未按各平台规范裁剪 |
